# 砼核 · Concrete Core（v2）

第三人称巨构探索游戏。值班员从值班室出发，调压开闸、恢复动力、乘轨车抵达砼核——一座 160 米高的中空混凝土塔——在升降台断电后沿北墙检修梯攀上主控层，重启砼核，最后登上 +132 米的冠顶。

## 本地运行

Node.js 18 或更新版本，在项目目录运行 `npm start`，打开 <http://127.0.0.1:4173>。无需安装依赖。

`npm test` 运行逻辑测试（角色碰撞、台阶与跳跃、移动平台、相机射线、阀门稳压、剧情顺序、升降台断电与重启、存档恢复、轨车停靠、角色步态）。

## 路线

| 区域 | 内容 |
| --- | --- |
| 值班室 | 阅读巡检工单（可跳过），打开检修门 |
| 泄洪廊 | 旁通阀小游戏：管压随来水波动，需把指针稳在绿色区间约 2.4 秒；可选攀登 23 米的转运梁检修梯 |
| 斜桥 · 动力间 | 合上三处隔离开关：地面、夹层楼梯之上、断开的悬挑检修道尽头（需助跑跳过断口），再合总闸 |
| 轨道栈桥 | 驾驶检修轨车或步行前往砼核，供电后沿途灯光依次亮起 |
| 砼核 | 升降台上行至 +048 时断电；沿北墙四段折返梯（240 级）攀至 +096 主控层，重启后井壁灯自下而上点亮，升降台来接你登顶 |
| 冠顶 | 记录巡检，镜头环绕砼核；可继续漫游寻找剩余档案 |

沿途散落 8 份巡检档案，讲述这座建筑与建造者的片段。按 J 或右上角档案键查看。

### 开发者模式

在 系统设置 → 开发者模式 中开启（设置会保存）：

- **移动速度**：0.5× – 8×，同时作用于行走、奔跑和飞行。
- **双击空格飞行**：与 Minecraft 创造模式相同。双击空格起飞，按住空格上升、Shift 下降，再双击空格或落地即结束飞行。
- **飞行时穿墙**：飞行时忽略碰撞，便于查看结构内部。
- **传送**：直接跳到值班室、旁通阀、转运梁、动力间、检修道、栈桥、砼核各层与冠顶（只改变位置，不改变剧情进度）。
- 开启后从高处坠落不会重置位置，右下角显示坐标、帧率和移动状态。

## 代码结构

```
src/
  main.js            菜单、对话框、档案阅读、设置、存档
  engine/            physics.js（可绕竖轴旋转的盒体碰撞、角色控制、移动平台、相机射线）
                     input.js（键鼠 / 指针锁定 / 触屏 / 手柄）camera.js（第三人称相机）audio.js（合成声场）
  game/              game.js（主循环与模式：行走 / 阀门 / 轨车 / 结尾）site.js（剧情旗标与机械状态，纯逻辑）
                     quest.js（目标与指引）lore.js（档案文本）layout.js（所有共享坐标）
  world/             builder.js（批量实例化 + 碰撞体生成）zones.js（值班室、泄洪廊、梯塔、斜桥、动力间、栈桥）
                     core.js（砼核主体）coreworks.js（升降台、安全门、井壁灯、信标、主控台）machines.js · pickups.js · scenery.js
  render/            材质、日光、后期、水面、尘埃与光幕
  actor/             worker.js（程序化巡检员与步态 IK）player.js（角色手感：加速、土狼时间、跳跃缓冲、落地）
```

第一版原样保存在 `legacy-v1/`，可通过 <http://127.0.0.1:4173/legacy-v1/> 打开对比。
